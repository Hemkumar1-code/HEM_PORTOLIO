Problem

Food polling and billing required employees and administrators to handle repetitive communication and data updates manually.

Solution

Meal Desk connects scheduled polling, WhatsApp responses, Google Sheets, booking confirmation and billing into one automated workflow.

Result

Employees can respond through WhatsApp while the workflow handles the underlying data processing and booking flow.

Technology

Built with

n8n

The core workflow engine. All automation logic, scheduling, branching and API calls are built as n8n nodes and connected in a visual workflow canvas.

WhatsApp API

Used for both outbound polling messages to employees and inbound response capture via a webhook listener. WhatsApp was chosen because it is already the primary communication tool for employees.

Google Sheets

Acts as the database layer — storing the food menu, employee registry, daily responses, confirmed bookings, and billing records. The n8n Google Sheets node reads and writes data in real time.

Webhooks & REST APIs

Webhooks listen for incoming WhatsApp messages and canteen scan events. The n8n Code node and HTTP Request node handle custom business logic and API calls throughout the workflow.
