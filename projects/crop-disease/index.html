Problem

When a farmer's crop gets a disease, they don't know what it is or what medicine to apply. Seeing an agri officer takes days; buying medicine based on a shopkeeper's guess risks crop damage and financial loss.

Solution

Farmer uploads a leaf photo on the website. Gemini Vision AI identifies the crop, disease and severity. An AI Agent generates full Tamil treatment guidance — organic remedies, chemical options, prevention tips — and a video script.

Result

Farmers get an instant, accurate diagnosis and actionable steps in their own language. No ML model training needed — just ready-made AI + n8n automation working together end to end.

Technology

Built with

n8n

The core workflow engine. Webhook trigger, Gemini API call, IF branching, AI Agent orchestration and response building are all n8n nodes connected in a visual canvas.

Google Gemini (Vision + Language)

Gemini Vision analyzes the uploaded leaf image and returns crop name, disease and severity in JSON. Gemini Chat Model powers the AI Agent that writes full Tamil treatment guidance.

Webhooks & REST API

The n8n Webhook node receives the farmer's photo from the website via HTTP POST. The HTTP Request node calls the Gemini Vision API with the base64-encoded image.

Website (HTML / JavaScript)

Simple front-end where the farmer selects a leaf photo and submits. JS encodes it and sends to n8n webhook. The Tamil solution and video are rendered directly on the page.
