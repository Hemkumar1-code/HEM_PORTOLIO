AI Crop Disease
Detection & Solution System

A farmer uploads a leaf photo — the system uses Gemini Vision AI to detect the disease, assess severity, and deliver step-by-step treatment guidance in Tamil, with an explainer video. No ML training needed. No agri officer required.

Problem

When a farmer's crop gets a disease, they don't know what it is, what caused it, or what medicine to apply. Seeing an agri officer takes time; buying medicine based on a shopkeeper's guess risks crop damage.

Solution

Farmer uploads a leaf photo on the website. Gemini Vision AI identifies the crop, disease and severity. An AI Agent then generates full Tamil treatment guidance — organic remedies, chemical options, prevention tips — and a video explainer.

Result

Farmers get an instant, accurate diagnosis and actionable steps in their own language. No training data, no ML model — just AI + automation working together. Future: WhatsApp integration & area-wise disease dashboard.

Technology

Built with

n8n

Core workflow engine. Webhook trigger, Gemini API call, IF branching, AI Agent orchestration and response building are all n8n nodes connected in a visual canvas.

Google Gemini (Vision + Language)

Gemini Vision analyzes the uploaded leaf image and returns crop name, disease, severity in JSON. Gemini Chat Model powers the AI Agent that writes full Tamil treatment guidance.

Webhook & REST API

The n8n Webhook node receives the farmer's photo from the website via HTTP POST. The HTTP Request node calls the Gemini Vision API with the base64-encoded image.

Website (HTML / JS)

Simple front-end where the farmer selects a leaf photo and submits. The JS reads the file, encodes it and sends it to the n8n webhook. The response (text solution + video) is rendered on the page.
